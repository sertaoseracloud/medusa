## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Binance depth stream → `normalizeDepth` | Untrusted third-party payload shape crosses here |
| `book:` topic → browser DOM | Exchange-supplied price strings are rendered here |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-14 | Denial of Service | `normalizeDepth` | mitigate | Malformed/short/missing depth arrays default to empty rather than throwing; the `openBinanceStream` try/catch from Plan 02-01 keeps a bad upstream frame from killing the stream handler |
| T-02-15 | Denial of Service (resource exhaustion) | book stream lifecycle | mitigate | The same refcounted supervisor governs book streams: exactly one upstream connection per symbol, closed at the last release, so pair-switching cannot accumulate orphaned 100ms streams |
| T-02-16 | Information Disclosure | `book:` topic | accept | Order book depth is public market data with no user-specific content; the topic is intentionally public and needs no per-user authorization (unlike `account:`) |
| T-02-17 | Tampering | rendering exchange price strings | accept | Values render as React text nodes only; no `dangerouslySetInnerHTML` and no numeric coercion that could silently alter displayed precision |
| T-02-SC | Tampering | npm installs | accept | Only the official shadcn `table` component is added; no npm package with `[ASSUMED]` provenance is installed |
</threat_model>
