<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Binance REST → symbol ingestion | Untrusted external data is written into the database |
| Authenticated browser → `POST /symbols/sync` | An operator-triggered outbound call to a rate-limited third party |
| Boot sequence → server availability | A failure here must not deny service |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-EXCH03tx | Tampering / Denial of Service | `sync-symbols.use-case.ts` | mitigate | The delete and the insert share one Drizzle transaction, so a mid-flight failure rolls back and the previous symbol set survives (D-15); asserted by `tests/symbols/sync-atomicity.test.ts` (fixes the legacy unguarded `deleteAll()` + `bulkInsert()`) |
| T-01-BOOTDOS | Denial of Service | Boot-time sync | mitigate | Registered on `onListen`, never `onReady`, and wrapped in try/catch, so a Binance outage logs an error while the server keeps serving (D-16, Pitfall 5); asserted by the "boot survives a failing exchange" test |
| T-01-EMPTYWIPE | Tampering | Adapter returning zero symbols | mitigate | An empty adapter result throws instead of committing an empty replace, so a degraded upstream response cannot silently erase the symbol table |
| T-01-SYNCFLOOD | Denial of Service | `POST /symbols/sync` | mitigate | Per-route `rateLimit { max: 5, timeWindow: '1 minute' }` plus a disabled button while in flight keeps the operator inside Binance's rate budget |
| T-01-SYMAUTH | Elevation of Privilege | `GET /symbols`, `POST /symbols/sync` | mitigate | Both routes carry the `authenticate` preHandler; an unauthenticated caller cannot trigger outbound exchange traffic |
| T-01-SYMINJ | Tampering | Exchange-supplied symbol strings | mitigate | Rows are written through the Drizzle query builder (parameterized) and rendered by React (escaped); numeric-ish fields are stored as text and never evaluated |
| T-01-FOUND04y | Tampering | `GET /symbols` querystring | mitigate | Zod querystring schema validates `quote` and `search` before the filter reaches SQL |
</threat_model>
