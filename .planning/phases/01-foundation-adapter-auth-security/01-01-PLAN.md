## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Fastify REST API | All request bodies, headers and origins are untrusted and cross here |
| Fastify process → PostgreSQL | Query parameters cross here; must stay parameterized |
| Fastify process → environment/secrets | `JWT_SECRET` / `AES_KEY` enter the process here |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-SEC05 | Spoofing / Information Disclosure | `@fastify/cors` registration in `src/app.ts` | mitigate | Explicit origin allowlist parsed from `CORS_ORIGINS`; `origin: true` and bare `cors()` are forbidden by acceptance criteria grep (RESEARCH.md Security Domain, CORS misconfiguration row) |
| T-01-SEC08a | Denial of Service | All API routes | mitigate | `@fastify/rate-limit` global `max: 100 / 1 minute` (D-22); the stricter login rule is added in Plan 02 |
| T-01-FOUND04 | Tampering | Every route body/params/querystring | mitigate | Zod schema compiled per route via `fastify-type-provider-zod`; unvalidated handlers cannot receive traffic |
| T-01-V7 | Information Disclosure | Unhandled exceptions and log output | mitigate | Central `setErrorHandler` returns a fixed `'Internal server error'` string for unknown errors; pino `redact` covers authorization header, password and secretKey/accessKey paths (SEC-07 foundation) |
| T-01-V6 | Tampering / Elevation of Privilege | `security/secrets.ts` | mitigate | Fail-fast in production when `JWT_SECRET`/`AES_KEY` are absent (D-23); dev fallback is a fresh in-memory `randomBytes(32)`, never a literal (D-24) |
| T-01-SQLI | Tampering | Drizzle queries against PostgreSQL | mitigate | Drizzle query builder parameterizes by default; Zod rejects malformed input before it reaches a repository |
| T-01-SC | Tampering | npm installs in Task 1 | mitigate | All packages carry an OK/Approved disposition in RESEARCH.md Package Legitimacy Audit; `ccxt` and `vitest` are audited [SUS] false positives and Task 1 re-verifies both `repository.url` values before install; `npm audit --audit-level=high` gates the task |
