<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Authenticated browser → `PUT /settings/credentials` | The highest-value secret in the system crosses here |
| Backend → Binance REST | Submitted credentials are exercised against the live exchange before storage |
| Backend → PostgreSQL | Only sealed ciphertext crosses; plaintext must not |
| Backend → log sink | Request bodies containing credentials pass near the logger |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-SEC07 | Information Disclosure | `settings.dto.ts` and the route response schema | mitigate | Masking applied once at the DTO boundary (D-05); the Zod response schema cannot express a raw secret; `tests/settings/response-shape.test.ts` asserts neither raw value appears in any response body (fixes the legacy controller that returned `secretKey` verbatim) |
| T-01-SEC07log | Information Disclosure | pino output for save requests | mitigate | `redact` paths from Plan 01 cover `req.body.accessKey`/`req.body.secretKey` plus bare `accessKey`/`secretKey`; asserted against captured log output |
| T-01-SEC01s | Information Disclosure | `settings` table at rest | mitigate | Only `v1:`-prefixed AES-256-GCM ciphertext is written; a database dump without `AES_KEY` yields nothing usable |
| T-01-BADCRED | Spoofing / Repudiation | Credential save flow | mitigate | `adapter.testConnection` must resolve before any write (D-06); the failure-path test asserts the row count is unchanged |
| T-01-EXCHERRm | Information Disclosure | Error responses on failed saves | mitigate | Only the four curated Portuguese domain messages are emitted (D-07); raw ccxt error text, which can echo request parameters, never reaches the body |
| T-01-IDOR | Elevation of Privilege | Settings routes | mitigate | The user id comes from the verified JWT (`request.user.sub`), never from the body or a query parameter; `user_id` is unique so one operator cannot address another's row (D-08) |
| T-01-FOUND04s | Tampering | `PUT /settings/credentials` body | mitigate | Zod body schema with minimum lengths; malformed bodies are rejected as per-field 400s before reaching the use case |
</threat_model>
