# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope covered by this contract:** login screen (email/password), password-change screen (with env-var-revert warning per D-04), Binance credentials settings screen (masked secretKey, test-before-save, per-failure-type errors per D-06/D-07), and the symbol-sync surface (automatic-on-boot status + manual "sync now" trigger per D-13–D-16). This is the Walking Skeleton slice: login → settings → symbol sync must all be visibly reachable in the UI.

**Setup note:** The current `frontend/` directory is React 18 + Vite 2.9 (legacy) and has no `components.json` — no existing design system was detected. FOUND-03 rewrites the frontend on React 19 + Vite from scratch, so shadcn is not being retrofitted onto the legacy app; it should be initialized as part of the Phase 1 frontend scaffold task using the preset declared below. This spec is written as the target contract for that new frontend, not as a description of anything currently in the repo.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing (form field internal padding) |
| md | 16px | Default element spacing (between form fields, card padding) |
| lg | 24px | Section padding (card/page section separation) |
| xl | 32px | Layout gaps (page margins on desktop) |
| 2xl | 48px | Major section breaks (login card vertical centering offset) |
| 3xl | 64px | Page-level spacing (not heavily used — single-column forms this phase) |

Exceptions: none. This phase has no icon-only touch targets requiring the 44px minimum (all interactive elements are full-width or labeled buttons/inputs).

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 (regular) | 1.5 |
| Label | 14px | 600 (semibold) | 1.5 |
| Heading | 20px | 600 (semibold) | 1.2 |
| Display | 28px | 600 (semibold) | 1.2 |

Exactly two weights declared (400, 600) and four sizes (14/16/20/28), per contract rule. `Display` is used only for the login card title ("Beholder") and settings page top-level heading; `Heading` for card/section titles (e.g., "Credenciais da Binance", "Sincronização de símbolos"); `Label` for form field labels and status badges; `Body` for all form input text, helper text, and error/warning copy.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0A0E14` (near-black slate, dark theme background) | Page background, app shell |
| Secondary (30%) | `#151B26` (dark slate-gray) | Cards (login card, settings card, sync-status card), input backgrounds |
| Accent (10%) | `#3B82F6` (blue-500) | Primary CTA buttons ("Entrar", "Salvar credenciais", "Sincronizar agora"), active nav/focus rings, links (e.g., "Trocar senha" link) |
| Destructive | `#EF4444` (red-500) | Error alerts (invalid credentials, connection test failure, validation errors), the password-change env-var-revert warning banner, "Sair" (logout) button |

Accent reserved for: the three primary action buttons listed above, input focus ring, and the single settings-to-password-change navigation link. Never applied to body text, card backgrounds, or decorative elements.

Destructive reserved for: credential test-connection failure alerts (D-06/D-07), Zod field-validation error text under inputs (D-25), the persistent warning banner on the password-change screen (D-04), and the logout button (session termination is the one irreversible-feeling action exposed in this phase).

## Copywriting Contract

All copy in Portuguese, matching project convention (REQUIREMENTS.md, CONTEXT.md are authored in Portuguese).

| Element | Copy |
|---------|------|
| Primary CTA — Login | "Entrar" |
| Primary CTA — Settings (save credentials) | "Salvar credenciais" |
| Primary CTA — Symbol sync (manual trigger) | "Sincronizar agora" |
| Primary CTA — Password change | "Atualizar senha" |
| Empty state heading (symbols table, before first sync) | "Nenhum símbolo sincronizado ainda" |
| Empty state body | "A sincronização automática ocorre na próxima inicialização do servidor. Clique em \"Sincronizar agora\" para forçar a sincronização imediatamente." |
| Error — invalid API key/secret (D-07) | "Chave ou segredo inválidos. Verifique as credenciais geradas no painel da Binance e tente novamente." |
| Error — insufficient permission (D-07) | "As credenciais são válidas, mas não têm permissão de leitura de saldo. Habilite essa permissão no painel da Binance." |
| Error — exchange unreachable/timeout (D-07) | "Não foi possível conectar à Binance agora (timeout ou serviço indisponível). Tente novamente em alguns instantes." |
| Error — login failure (generic, single-user system) | "Email ou senha incorretos." |
| Error — login rate-limited (D-20) | "Muitas tentativas. Aguarde alguns minutos antes de tentar novamente." |
| Error — validation (Zod field errors, D-25) | Inline per-field message under each input (e.g., "Formato de email inválido") — never a generic top-level "erro de validação" banner |
| Warning — password change screen (D-04, persistent) | "Atenção: esta senha será revertida para o valor da variável de ambiente no próximo restart do servidor, caso a variável não seja atualizada junto." |
| Destructive confirmation — Logout | "Sair": no confirmation dialog required (session termination is fast to recover from — same email/password login) |
| Sync status badge (auto-sync ran at boot, succeeded) | "Sincronizado" |
| Sync status badge (auto-sync failed at boot, D-16) | "Sincronização inicial falhou — clique para tentar novamente" |
| Sync status badge (sync in progress) | "Sincronizando…" |
| Credential masking format (D-05, Claude's Discretion) | Show only the last 4 characters of `secretKey`, prefixed with a fixed-width mask, e.g. `••••••••••••ab12` — never render `accessKey`/`secretKey` in full under any circumstance |
